Generalizability Theory for LLM-as-Evaluator Reliability

Code and saved results for the revised study by Jin Liu and Robert A. Perera. Reports cover Hate-Speech, Mental-Health and Drug-Review annotations across evaluators, prompts, temperatures and seeds.

  1. Labelling: a pointer to the prompts in the Supplementary Materials and archived annotations.
  2. Primary analysis — OpenMx: specification comparisons, joint variance/covariance estimates, reliability and bootstrap intervals.
  3. Supportive analysis — lme4 and method of moments: completed point estimates, stacked covariance-restriction analyses and univariate diagnostics.
  4. Other analysis: agreement, entropy, calibration, archived facet-severity intervals and cross-trait diagnostics.

The primary reports cover seven outcome sets: four univariate codings and three joint multivariate vectors. Each outcome set has 1,000 accepted bootstrap fits and 100 completed leave-one-item-out fits.

The updated lme4 reports compare the same eleven specifications and provide REML point estimates without intervals. The multivariate sensitivity fits traits together with diagonal source variances and one shared residual, using the current Mental-Health six-flag and three-OR-group outcomes and the four Drug-Review aspects. The five reports include 106 downloadable output files.

Read or reproduce

Use the links above to read the reports in your browser. For offline access, download this repository and open index.html. Code and outputs are contained within the HTML files. The ten OpenMx and lme4 G-theory reports include their complete source through the Code menu; no separate Rmd files are distributed. Data, source extraction and environment instructions explain how to rerun an analysis.

The prior public R implementation remains available in the pre-openmx-r1 archive tag. It is distinct from the current supplementary lme4 reports here.
