Hate-Speech: archived facet-severity intervals

Saved evaluator, prompt, and temperature contrasts supporting Supplementary Table S9.

This page preserves the completed historical severity analysis. Packaging on 2026-09-10 did not refit the ordinal model or rerun its bootstrap. These intervals belong to the ordinal facet-severity analysis, separate from the current point-only lme4 G-theory reports.

Method

The historical analysis fitted MASS::polr(sev ~ evaluator + prompt + temp, method = "logistic"). The ordered outcome used the corpus severity score. Reference levels were gpt-4o-mini, rubric, and temperature 0. Temperature entered as a factor. Seed was retained within the resampled item block and was not a coefficient in this model.

Each replicate sampled 100 items with replacement and retained all 216 annotations for every sampled item. The point fit used Hess = TRUE; bootstrap fits used Hess = FALSE. Only fits with optimizer convergence code 0 contributed. With seed 20260805, 1000 attempted replicates were saved; all 1000 were usable for every contrast. Cluster SEs are the standard deviations of the bootstrap coefficients. The displayed 95% intervals are percentile intervals (R’s default quantile type 7); no jackknife or BCa correction enters this analysis.

Naive and clustered Wald p-values are shown alongside the percentile intervals, as in the saved output. They use different inferential calculations and need not yield identical threshold decisions. Positive coefficients indicate greater severity for Hate-Speech/Mental-Health and more positive sentiment for Drug-Review. The historical source did not test proportional odds; these are descriptive facet contrasts.

Reproduction

  1. Download the standalone R script, saved CSV(s), and bootstrap cache(s) below into the same folder.
  2. Run the default verification command. It reconstructs the cluster SEs, percentile intervals, effective counts, and Wald summaries from the saved bootstrap coefficients and saved point estimates. It performs no model fits and writes no files.
Rscript reproduce_facet_severity_hate_speech.R

To explicitly rerun the analysis, obtain hate_labeling_final.csv from the linked OSF data repository and place it in a data/ folder beside the script. The script verifies its MD5 checksum before fitting. The archived environment reported R 4.5.3 and MASS 7.3-65. The standalone fitting path executes serially and preserves the original pre-generated item draws; its output must go to a new directory.

Rscript reproduce_facet_severity_hate_speech.R --refit --data-dir=data --output-dir=new_severity_run

The standalone wrapper adapts file paths, cache verification, and serial execution. The model formula, scoring, reference levels, item-block sampling, convergence filtering, and inferential calculations follow the historical source. The default check retains the saved point estimates and naive SEs; it does not independently refit or validate them.

opt <- function(prefix, default) {
  z <- args[startsWith(args, prefix)]
  if (length(z) > 1L) stop("Repeated option: ", prefix)
  if (length(z)) substring(z, nchar(prefix) + 1L) else default
}

do_refit <- "--refit" %in% args
output_dir <- opt("--output-dir=", file.path(asset_dir, "refitted_facet_severity"))

SCORINGS <- c("single")
asset_names <- function(sc) {
  suffix <- if (DATASET == "mental_health") paste0("_", sc) else ""
  list(csv = paste0("facet_severity_clustered_", DATASET, suffix, ".csv"),
       cache = paste0("boot_cache_severity", suffix, ".rds"),

close_enough <- function(a, b) {
  if (!identical(is.na(a), is.na(b))) return(FALSE)
  all(abs(a[!is.na(a)] - b[!is.na(b)]) <= 1e-10 * pmax(1, abs(b[!is.na(b)])))
}
summarize_draws <- function(bs, est, se_naive, sc) {
  rows <- lapply(names(est), function(k) {
    v <- bs[, k]; v <- v[is.finite(v)]
    enough <- length(v) >= SEV_MIN_B
    se_cl <- if (enough) sd(v) else NA_real_
    ci <- if (enough) quantile(v, c(.025, .975), names = FALSE) else c(NA_real_, NA_real_)
    prefix <- if (DATASET == "mental_health")
      data.frame(dataset = paste0(DATASET, "_", sc), scoring = sc) else data.frame(dataset = DATASET)
    cbind(prefix, data.frame(term = k, coef = est[[k]], B = B_BOOT,
      B_effective = length(v), jack_effective = NA_integer_,
      se_naive = se_naive[[k]],
      p_naive = 2 * pnorm(-abs(est[[k]] / se_naive[[k]])),
      p_cluster = 2 * pnorm(-abs(est[[k]] / se_cl)), se_cluster = se_cl,
      se_ratio = se_cl / se_naive[[k]], ci_lo = ci[1], ci_hi = ci[2],
      crosses_zero = (ci[1] <= 0 && ci[2] >= 0), row.names = NULL))
  })
  do.call(rbind, rows)
}

# Verification needs only the downloaded CSVs and coefficient caches. It does
# not call polr(), reconstruct point estimates, or claim new model convergence.
for (sc in SCORINGS) {
  nm <- asset_names(sc)
  saved <- read.csv(file.path(asset_dir, nm$csv), stringsAsFactors = FALSE)
  cache <- readRDS(file.path(asset_dir, nm$cache)); bs <- cache$value
  stopifnot(identical(cache$fp$key, nm$key), identical(cache$fp$data_md5, DATA_MD5),
    cache$fp$seed == SEED, cache$fp$B == B_BOOT,
    is.matrix(bs), nrow(bs) == B_BOOT, identical(colnames(bs), saved$term),
    !is.null(attr(bs, "n_nonconverged")),
    attr(bs, "n_nonconverged") == sum(!complete.cases(bs)))
  est <- setNames(saved$coef, saved$term)
  se_naive <- setNames(saved$se_naive, saved$term)
  rebuilt <- summarize_draws(bs, est, se_naive, sc)
  stopifnot(identical(names(rebuilt), names(saved)), identical(rebuilt$term, saved$term))
  for (k in names(saved)) {
    if (is.numeric(saved[[k]]) || all(is.na(saved[[k]]))) stopifnot(close_enough(rebuilt[[k]], saved[[k]]))
    else stopifnot(identical(rebuilt[[k]], saved[[k]]))
  }
  cat(sprintf("%s: verified %d saved contrasts, B=%d, effective B=%d..%d, failed=%d; no fitting\n",
    nm$csv, nrow(saved), B_BOOT, min(saved$B_effective), max(saved$B_effective),
    sum(!complete.cases(bs))))
  print(saved, row.names = FALSE)
}

load_scoring <- function(sc) {
  score <- if (DATASET == "mental_health") as.numeric(MAPS[[sc]][raw$label]) else as.numeric(raw$severity)
  if (any(is.na(score))) stop("Unmapped outcome values")
  data.frame(score = score, item = factor(raw$item_id), evaluator = factor(raw$evaluator),
    prompt = factor(raw$prompt_type), temp = factor(raw$temperature), seed = factor(raw$seed),
    stringsAsFactors = FALSE)
}
ref_if <- function(f, lev) { f <- factor(f); if (lev %in% levels(f)) relevel(f, lev) else f }
dir.create(output_dir, recursive = TRUE)
for (sc in SCORINGS) {
  # Reset separately for both MH scorings, as in the archived implementation.
  set.seed(SEED)
  ds <- load_scoring(sc)
  ds$sev <- factor(ds$score, ordered = TRUE)
  ds$evaluator <- ref_if(ds$evaluator, "gpt-4o-mini")
  ds$prompt <- ref_if(ds$prompt, "rubric")
  ds$temp <- ref_if(ds$temp, "0")
  FORM <- sev ~ evaluator + prompt + temp
  fit_sev <- MASS::polr(FORM, data = ds, Hess = TRUE, method = "logistic")
  if (!identical(as.integer(fit_sev$convergence), 0L)) stop("Facet-severity model did not converge")
  est <- coef(fit_sev)
  se_naive <- sqrt(diag(vcov(fit_sev)))[names(est)]
  idx_by_item <- split(seq_len(nrow(ds)), ds$item); items <- names(idx_by_item)
  picks_sev <- lapply(seq_len(B_BOOT), function(b) sample(items, length(items), replace = TRUE))
  one_sev <- function(pick) {
    rid <- unlist(idx_by_item[pick], use.names = FALSE)
    fb <- try(MASS::polr(FORM, data = ds[rid, ], Hess = FALSE, method = "logistic"), silent = TRUE)
    out <- setNames(rep(NA_real_, length(est)), names(est))
    if (!inherits(fb, "try-error") && identical(as.integer(fb$convergence), 0L)) {
      cb <- coef(fb); out[names(cb)] <- cb
    }
    out
  }
  bs <- do.call(rbind, lapply(picks_sev, one_sev)); colnames(bs) <- names(est)
  attr(bs, "n_nonconverged") <- sum(!complete.cases(bs))
  nm <- asset_names(sc)
  fresh <- summarize_draws(bs, est, se_naive, sc)
  write.csv(fresh, file.path(output_dir, nm$csv), row.names = FALSE)
  saveRDS(list(fp = list(key = nm$key, data_md5 = DATA_MD5, seed = SEED, B = B_BOOT),
    settings = list(estimator = "MASS::polr logistic", r_version = R.version.string,
      MASS_version = as.character(packageVersion("MASS")), workers = 1L),
    value = bs), file.path(output_dir, nm$cache))
  cat("Explicit refit saved to ", output_dir, "\n", sep = "")
}

# below SEV_MIN_B usable draws the clustered SE, its p-value, and the percentile
# interval are withheld (NA) rather than computed from a handful of draws.
# B_effective records how many refits succeeded either way.
SEV_MIN_B <- 50L
sev_rows <- lapply(names(est), function(k) {

# contrasts are read as descriptive facet severities, not as a fitted
# cumulative-odds model whose link has been checked.
# Like-for-like: the SAME Wald procedure before and after clustering.  Crossing
# a clustered p-value against a clustered interval compares two clustered
# procedures with each other, which is a numerical curiosity, not the finding
# this section exists to report.  %in% TRUE guards the NA that p_cluster carries

# ---- Historical killed-worker helper ----
drop_dead <- function(x, n_quant) {
  bad <- !vapply(x, function(z) is.numeric(z) && length(z) == n_quant, logical(1))
  if (any(bad)) {
    cat(sprintf("note: %d of %d replicates failed or were killed; recorded as NA\n",
                sum(bad), length(x)))
    nm <- NULL
    ok <- which(!bad)
    if (length(ok)) nm <- names(x[[ok[1]]])
    x[bad] <- list(setNames(rep(NA_real_, n_quant), nm))
  }
  x
}
